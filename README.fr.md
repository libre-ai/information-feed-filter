# Libre AI Information Feed Filter

Transformer vos abonnements à des sources d’information en une sélection que vous pouvez examiner et comprendre. Ce produit vise les personnes suivant plusieurs sources qui souhaitent choisir leurs lectures, sans recommandations inexpliquées.


## Usages visés

- Réunir des sources auxquelles vous êtes abonné pour les examiner.
- Sélectionner des éléments avec des règles explicites et voir pourquoi chacun a été retenu.
- Exporter cette sélection en conservant les sources et les dates utiles.

**Aujourd’hui :** ce dépôt présente le projet sous forme de documentation ; aucune application n’est encore disponible.
